# Methodology

The case study uses a 60/20/20 stratified train, validation and test design with seed 42. Four-fold stratified training CV optimizes average precision, which summarizes ranking for the minority departure class. Each family has six combinations in its grid. The family with the highest CV average precision is chosen before test outcomes are examined. Its margin over the runner-up is small enough to warrant confirmation on a new labeled sample.

Selected configurations are fitted on the training partition. Each family also receives a sigmoid candidate fitted on cross-validated training predictions. Validation Brier score decides whether to use the original or calibrated probabilities. Validation F1 selects the operating cutoff, preferring the higher probability in an exact tie. Test precision, recall, F1 and accuracy use that cutoff with an inclusive comparison. ROC-AUC, average precision and Brier use full-resolution scores. Plot bins with fewer than five test records are suppressed. The selected model’s stratified bootstrap intervals use 500 test resamples with positive and negative counts fixed and reflect test sample uncertainty conditional on the fit.

The preprocessing pipeline learns median and modal imputation, categorical levels and logistic standardization within training folds. Raw-feature allowlisting excludes age, gender, marital status, unknown columns, identifiers and the target. The pipeline also excludes fields constant in the fit partition. Identical recognized source profiles are collapsed before splitting. Training stops with a clear message if identical predictors remain across distinct source records and would risk split leakage. The dataset includes fields with undocumented collection timing. Before transferring to operational data, confirm those features came before the outcome.

Held-out permutation diagnostics measure how much shuffling each input changes average precision. The local baseline replaces one input at a time with a training median or mode, so interactions and derived terms are rescored through the same pipeline. Related inputs can share effects and perturbations can create profiles uncommon in the observed sample. Individual differences are nonadditive. Workload and engagement constructs are descriptive features.
